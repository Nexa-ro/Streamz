# Streamz

### Live Media & Creator Platform

Streamz is a live-first media application under active development, focused on real-time broadcasting, creator and community experiences, live discovery, engagement, monetization concepts, and interactive media.

**Status:** Active Development

> This public repository currently serves as a portfolio and product-documentation repository. The complete application source is not published here.

---

## Project Overview

Streamz is being developed as a mobile-first live media ecosystem where viewers can discover live content and creators can build interactive audiences around real-time experiences.

Engineering and product areas include:

- Live streaming experiences
- Real-time audience interaction
- Creator profiles and communities
- Live discovery and feeds
- Gifts and creator monetization concepts
- Wallet-related workflows
- Rankings and engagement systems
- Moderation and safety concepts
- Mobile application development
- Backend APIs and real-time services

Some capabilities are implemented and tested during development, while others remain experimental, planned, or under active integration.

## Live Streaming

The live-media layer is being developed around real-time broadcasting and interactive viewing experiences.

Development work includes:

- Live room and broadcast concepts
- Creator-to-viewer live experiences
- Real-time session events
- Audience participation
- Live state synchronization
- Mobile live-media integration

LiveKit is used in the live-media architecture, with Socket.IO supporting applicable real-time application events.

---

## Discovery

Streamz is designed around multiple ways of finding relevant live content, including product concepts such as:

- For You
- Following
- Trending
- Nearby
- Categories
- Location-aware live discovery concepts

The discovery system continues to evolve as part of the product's research and development.

---

## Creator & Community Experience

Creator-facing concepts include live broadcasting, profiles, audience engagement, gifts, subscriptions and monetization-related workflows, while viewers can discover, follow, interact with, and support creators.

The project is designed to explore how real-time content, community participation, and creator economics can work together in one mobile experience.

---

## Real-Time Engineering

Real-time development areas include:

- Live session events
- Presence and participation
- Interactive audience events
- Socket-based application updates
- Live-media session coordination
- Event-driven client/server workflows

This work provides practical experience with the engineering challenges involved in stateful and real-time applications.

## Monetization Concepts

Streamz includes product and engineering concepts around:

- Virtual gifts
- Creator wallets
- Subscriptions
- Creator earnings
- Rankings and engagement incentives
- Shops and creator commerce concepts
- Sponsorship and advertising workflows
