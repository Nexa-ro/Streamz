# Security Policy

Streamz is a live-media and creator platform under active development. Potential security or privacy issues should be reported responsibly and should not be disclosed through public GitHub issues.

## Reporting a Security Issue

A private report should identify the affected component, describe the issue and potential impact, include reproduction steps where appropriate, and use only sanitized screenshots or logs.

Do not include passwords, API keys, access tokens, private user data, production secrets, or sensitive media in reports.

## Security Areas

Relevant security areas include authentication and authorization, API security, real-time communication, live-media access, moderation and trust workflows, user privacy, and security-aware application development.

## Development Status

Streamz remains under active development. The public repository provides portfolio and product documentation and does not imply that every documented capability is production-ready.
